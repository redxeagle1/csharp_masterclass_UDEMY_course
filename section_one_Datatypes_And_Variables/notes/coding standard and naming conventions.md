## naming conventions in c#
there are 3 common naming conventions
- Camel case : `myVariableMe`
- Pascal case : `MyClassAnimal`
- Snake case : `my_variable_hamada`

### the naming convention for method,variables and collections
- method ,class => *Pascal*Case
- variables => *camel*Case

### best practises

- collaboratino : **Follow** the standards established by the team
